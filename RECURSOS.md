# 📚 Recursos

Una recopilación de links, tutoriales y materiales externos para 
seguir aprendiendo más allá de esta guía.

---

## 🐍 Python

- [Documentación oficial de Python](https://docs.python.org/es/3/) — la referencia oficial, en español
- [W3Schools Python](https://www.w3schools.com/python/) — tutoriales cortos con ejemplos interactivos
- [Real Python](https://realpython.com/) — artículos en profundidad (en inglés)
- [Python Tutor](https://pythontutor.com/) — visualiza cómo se ejecuta tu código paso a paso

---

## 🌐 Compiladores y editores online

- [Programiz](https://www.programiz.com/python-programming/online-compiler/) — compilador Python simple
- [Replit](https://replit.com/) — entorno completo online, permite guardar proyectos
- [Google Colab](https://colab.research.google.com/) — ideal para proyectos de datos e IA, gratis y en la nube

---

## 🔧 Git y GitHub

- [Documentación oficial de Git](https://git-scm.com/doc)
- [GitHub Docs](https://docs.github.com/es) — documentación oficial en español
- [Oh My Git!](https://ohmygit.org/) — juego interactivo para aprender Git visualmente
- [Learn Git Branching](https://learngitbranching.js.org/?locale=es_ES) — practica ramas y comandos con ejercicios visuales

---

## 🤖 Inteligencia Artificial y Machine Learning

- [Documentación de scikit-learn](https://scikit-learn.org/stable/) — la librería que usamos en la guía
- [Kaggle](https://www.kaggle.com/) — datasets gratuitos y competiciones para practicar
- [Google's Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) — curso gratuito de Google (en inglés)
- [3Blue1Brown - Redes Neuronales](https://www.youtube.com/watch?v=aircAruvnKk) — la mejor explicación visual de redes neuronales que existe

---

## 📺 Canales de YouTube recomendados

- **Píldoras Informáticas** — programación en español, muy didáctico
- **HolaMundo** — Python y proyectos prácticos en español
- **Dot CSV** — Inteligencia Artificial explicada en español
- **freeCodeCamp** — cursos completos gratuitos (en inglés, con subtítulos)
