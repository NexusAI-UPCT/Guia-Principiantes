# 5️⃣ Debugging

Todo programador —sin excepción— se pasa una buena parte de su 
tiempo corrigiendo errores. En esta sección aprenderás a hacerlo de 
forma eficiente, en vez de frustrarte cada vez que algo falla.

## 📚 Lecciones

### [01 - ¿Qué es el Debugging?](./01-Que-es-debugging.md)
Qué significa depurar código y por qué es una habilidad clave.

### [02 - Técnicas de Debugging](./02-Tecnicas-debugging.md)
Estrategias prácticas para encontrar y resolver errores paso a paso.

### [03 - Herramientas Útiles](./03-Herramientas-utiles.md)
El depurador de VS Code y otras herramientas que te ahorrarán horas.

## 🎯 Objetivos de esta sección

- [ ] Entender los tipos de errores que existen en programación
- [ ] Aprender a leer mensajes de error sin entrar en pánico
- [ ] Aplicar técnicas para encontrar la causa de un error
- [ ] Usar el depurador de VS Code

**Tiempo estimado:** 2 horas

---

## 💡 Un cambio de mentalidad

Si en los proyectos anteriores te encontraste con errores y 
lograste resolverlos, **ya estás haciendo debugging**, aunque no lo 
supieras. Esta sección le pone nombre y estructura a algo que ya 
empezaste a practicar.
