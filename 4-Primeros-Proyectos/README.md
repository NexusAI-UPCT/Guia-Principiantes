# 4️⃣ Primeros Proyectos

Ya tienes las bases de programación y sabes usar Git y GitHub. Es 
momento de construir proyectos reales, de principio a fin, aplicando 
todo lo aprendido.

## 📚 Proyectos

### [01 - Calculadora](./01-Calculadora.md)
Un programa que realiza operaciones matemáticas básicas por consola.

### [02 - Gestor de Tareas](./02-Gestor-tareas.md)
Una aplicación para añadir, ver y completar tareas pendientes.

### [03 - Web Scraper](./03-Scraper-web.md)
Un programa que extrae información automáticamente de una página web.

---

## 🎯 Objetivos de esta sección

- [ ] Construir un programa completo de principio a fin
- [ ] Aplicar variables, condicionales, bucles y funciones juntos
- [ ] Subir cada proyecto a tu propio repositorio en GitHub
- [ ] Ganar confianza para crear tus propias ideas

**Tiempo estimado:** 4-5 horas

---

## 💡 Cómo trabajar esta sección

Cada proyecto está pensado para hacerse **en tu computadora**, con 
VS Code, y subirse a GitHub siguiendo el flujo que ya conoces 
(`add`, `commit`, `push`). Te recomendamos crear un repositorio 
nuevo por cada proyecto, para practicar también esa parte.

**¡Empecemos!** → [Calculadora](./01-Calculadora.md)
