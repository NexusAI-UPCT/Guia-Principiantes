# Tu Primer Programa

## 🎯 Objetivo

Vas a escribir y ejecutar tu primer programa en Python: el clásico 
"Hola Mundo". No necesitas instalar nada todavía — vamos a usar una 
página web para programar directamente desde tu navegador.

---

## 🌐 Usa un compilador online

Para empezar, olvídate de instalar programas. Usa una de estas 
páginas donde puedes escribir y ejecutar Python directamente:

### Opción recomendada: [Programiz](https://www.programiz.com/python-programming/online-compiler/)

1. Entra a [programiz.com/python-programming/online-compiler](https://www.programiz.com/python-programming/online-compiler/)
2. Verás una pantalla dividida: código a la izquierda, resultado a la derecha
3. Borra lo que haya escrito y empieza desde cero

### Otras opciones válidas:
- [Replit](https://replit.com/languages/python3) — más completo, permite guardar proyectos
- [Python Tutor](https://pythontutor.com/) — ideal para ver paso a paso qué hace tu código

> 💡 **¿Por qué empezar así?** Instalar Python y un editor puede ser 
> confuso al principio. Primero aprende a programar, luego instalamos 
> las herramientas profesionales (lo veremos en la sección de GitHub).

---

## ✍️ Escribiendo tu primer código

En el compilador online, escribe esta línea:

```python
print("¡Hola, mundo!")
```

Luego busca el botón **Run** (o ▶️) y haz clic.

Deberías ver en el resultado: ¡Hola, mundo!



🎉 **¡Felicidades! Acabas de ejecutar tu primer programa.**

---

## 🔍 ¿Qué acaba de pasar?

Vamos a entender la línea que escribiste:

```python
print("¡Hola, mundo!")
```

| Parte | Qué es | Qué hace |
|---|---|---|
| `print` | Una **función** | Le dice a Python: "muestra esto en pantalla" |
| `( )` | Paréntesis | Contienen lo que quieres mostrar |
| `"¡Hola, mundo!"` | Un **string** (texto) | El mensaje que se va a imprimir |

`print()` es una de las funciones que más vas a usar: sirve para 
ver resultados, revisar valores y depurar errores.

---

## 🧪 Experimenta un poco

Prueba modificar el mensaje y ejecutar de nuevo:

```python
print("Me llamo Kaiqi y estoy aprendiendo a programar")
```

```python
print("2 + 2 =")
print(2 + 2)
```

```python
print("Primera línea")
print("Segunda línea")
print("Tercera línea")
```

> 💡 Cada `print()` nuevo escribe en una línea distinta.

---

## ⚠️ Errores comunes (¡son normales!)

Si algo falla, revisa esto:

- ❌ `print("Hola)` → Falta cerrar las comillas
- ❌ `Print("Hola")` → Python distingue mayúsculas: es `print`, no `Print`
- ❌ `print "Hola"` → Faltan los paréntesis

Los errores no son un fracaso, son parte normal de programar. 
Hasta los programadores expertos los tienen todos los días.
