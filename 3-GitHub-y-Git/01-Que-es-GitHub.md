# ¿Qué es GitHub?

## 🎯 Objetivo

Entender la diferencia entre **Git** y **GitHub**, y por qué la 
asociación organiza todo su trabajo (proyectos, reuniones, esta 
misma guía) a través de ellos.

---

## 🤔 Git vs GitHub: no son lo mismo

Es un error muy común confundirlos. Vamos a aclararlo:

| | **Git** | **GitHub** |
|---|---|---|
| **¿Qué es?** | Un programa (herramienta) | Una página web |
| **¿Qué hace?** | Guarda el historial de cambios de tu código | Guarda tus proyectos en la nube y permite compartirlos |
| **¿Dónde vive?** | En tu computadora | En internet |
| **Analogía** | El motor | El garaje donde aparcas el coche |

En resumen:
- **Git** = la herramienta que usas para guardar versiones de tu código
- **GitHub** = la plataforma online donde subes ese código para 
  guardarlo, compartirlo y colaborar con otros

> 💡 Existen alternativas a GitHub como GitLab o Bitbucket, pero 
> GitHub es la más usada en el mundo y la que usa la asociación.

---

## 📼 ¿Qué problema resuelve Git?

Imagina que estás escribiendo un trabajo en Word y quieres poder 
volver a una versión de hace 3 días, sin perder lo que has hecho 
después. O que tú y un compañero estáis editando el mismo documento 
a la vez, sin que uno borre el trabajo del otro.

Eso es exactamente lo que resuelve Git, pero para código:

- 📸 **Guarda "fotos" de tu proyecto** en el tiempo (llamadas *commits*)
- ⏪ Puedes **volver a una versión anterior** si algo se rompe
- 👥 Permite que **varias personas trabajen a la vez** sin pisarse el trabajo
- 📝 Deja un **historial**: quién cambió qué y cuándo

---

## 🌐 ¿Qué te permite hacer GitHub?

GitHub añade, sobre Git, todo lo necesario para trabajar en equipo:

- ☁️ **Guarda tu código en la nube** (no depende de tu computadora)
- 👀 Cualquiera puede **ver tu código** (si el repositorio es público)
- 🤝 Permite **colaborar**: varias personas suben cambios al mismo proyecto
- 🐛 Tiene herramientas para **reportar errores** (Issues) y **proponer cambios** (Pull Requests)
- 🏢 Permite crear **organizaciones** (como la nuestra: `NexusAI-UPCT`) 
  para agrupar todos los proyectos de un equipo

## 🏗️ Conceptos clave que vas a usar

No hace falta que los memorices ahora — los irás entendiendo en la 
práctica en las próximas lecciones. Aquí tienes un adelanto:

| Concepto | Qué es |
|---|---|
| **Repositorio (repo)** | Una carpeta de proyecto guardada con Git/GitHub |
| **Commit** | Una "foto" guardada de tu código en un momento concreto |
| **Push** | Subir tus cambios desde tu computadora a GitHub |
| **Pull** | Bajar cambios desde GitHub a tu computadora |
| **Branch (rama)** | Una copia paralela del proyecto para probar cosas sin afectar lo principal |
| **Clone** | Descargar una copia completa de un repositorio a tu computadora |

---

## 🧑‍🤝‍🧑 ¿Por qué la asociación usa GitHub?

Todo lo que ves organizado en `NexusAI` — proyectos, esta guía, 
documentación, actas de reuniones — vive en GitHub porque:

- Todo queda **centralizado** en un solo lugar
- Cualquier miembro puede **acceder y contribuir**
- Se guarda el **historial completo** de cada proyecto, incluso los antiguos
- Es el estándar que usan empresas y equipos de programación en todo el mundo

Aprender a usarlo aquí también te prepara para el mundo laboral: 
**GitHub es una herramienta que vas a usar durante toda tu carrera** 
como programador o en IA.

---

## ✅ Para quedarte con esto

- **Git** es la herramienta que guarda el historial de tu código
- **GitHub** es la web donde se sube, comparte y organiza ese código
- Permite trabajar en equipo sin perder ni pisar el trabajo de otros
- Es el estándar de la industria: aprenderlo ahora te sirve para siempre
