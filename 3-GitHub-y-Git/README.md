# 3️⃣ GitHub y Git

Hasta ahora has programado desde el navegador, sin instalar nada. 
En esta sección das el siguiente paso: vas a instalar las 
herramientas reales que usan los programadores, y a aprender **Git** 
y **GitHub** — el sistema que usamos para guardar, compartir y 
colaborar en código (incluida toda esta guía).
