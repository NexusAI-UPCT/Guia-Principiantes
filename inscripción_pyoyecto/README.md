# 📋 Inscripción de Proyectos — NEXUS AI UPCT

Esta carpeta reúne todo lo necesario para **proponer e inscribir un proyecto** en la asociación NEXUS AI.

> La asociación desarrolla un **máximo de 3 proyectos por curso**, por lo que las propuestas pasan por un proceso de selección.

## Contenido

| Archivo | Descripción |
|---|---|
| [01-como-presentar-un-proyecto.md](01-como-presentar-un-proyecto.md) | Proceso de inscripción, requisitos y criterios de selección |
| [02-normativa-uso-logos.md](02-normativa-uso-logos.md) | Reglas de uso del logotipo y la identidad visual |
| [03-formato-de-informes.md](03-formato-de-informes.md) | Tipografía, márgenes, sangría y estructura de los informes |
| [plantillas/](plantillas/) | Plantillas listas para copiar |
| [recursos/logos/](recursos/logos/) | Archivos oficiales del logo |

## Inicio rápido

1. Lee la guía de presentación.
2. Copia `plantillas/propuesta-proyecto.md` y rellénala.
3. Abre un **Pull Request** o un **Issue** con la etiqueta `nueva-propuesta`.
4. La junta directiva revisará tu propuesta y te responderá.
